Toolbox y código

Esta sección recopila diferentes toolboxes y entornos de software utilizados en quimiometría y análisis multivariante, especialmente orientados al tratamiento de datos espectroscópicos, imágenes hiperespectrales y análisis exploratorio de datos. Las herramientas incluidas permiten realizar desde descomposición de mezclas y resolución de señales, hasta análisis exploratorio, visualización avanzada y extracción de información relevante a partir de conjuntos de datos complejos.

  • MCR-ALS GUI 2.0
    Interfaz gráfica para la aplicación de Multivariate Curve Resolution–Alternating Least Squares (MCR-ALS) en MATLAB,, ampliamente utilizada para la resolución de mezclas químicas y la interpretación de perfiles espectrales y de concentración.
  • Multivariate Exploratory Data Analysis (MEDA) Toolbox
    Toolbox orientado al análisis exploratorio de datos multivariantes en MATLAB,, con énfasis en la interpretación de modelos (PCA, ASCA) y la identificación de relaciones entre variables.
  • HYPERTOOLS v3
    Conjunto de herramientas para el análisis y visualización de datos hiperespectrales en MATLAB, facilitando el preprocesado, la reducción de dimensionalidad, la interpretación de imágenes espectrales complejas y la construcion de modelos multivariantes.
  • Chemoface
    Plataforma integrada y simplificada para análisis quimiométrico que combina preprocesado, análisis multivariante y visualización, especialmente pensada para datos químicos y espectroscópicos.
  • CAT Chemometrics Agile Tool
    Software basado en R, para análisis quimiométrico que combina herramientas para DOE, preprocesado, análisis multivariante y visualización.
  • Chemotools
    Biblioteca versátil en Python, orientada a entornos de producción, que proporciona una plataforma unificada para el desarrollo de modelos quimiométricos. Integra metodologías de preprocesado espectral con la API de scikit-learn y el ecosistema de aprendizaje automático de Python, con el objetivo de estandarizar y simplificar la creación e implementación de modelos quimiométricos y de machine learning robustos para datos espectrales.
  • Lovelace's Square
    Repositorio de código y datos sin fines de lucro, desarrollado por y para la comunidad quimiométrica.
